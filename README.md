# Персональный ассистент Haystack + Pinecone

Учебный проект VPg06. Telegram-бот использует Haystack Agent и долговременную память Pinecone. Модель выбирает инструменты: случайный факт о кошках, получение и анализ фотографии собаки, текущая погода в городе.

## Возможности

- `weather` - новый инструмент на `ComponentTool`: геокодинг города и текущая погода Open-Meteo с единицами и временем измерения.
- `cat_fact` - реальный запрос к catfact.ninja.
- `analyze_dog` - фото Dog CEO, анализ именно полученных байтов моделью, отправка тех же байтов в Telegram с описанием в `caption`. Порода определяется предположительно.
- `PineconeDocumentStore` и `PineconeEmbeddingRetriever` - сохранение и поиск исходных сообщений пользователя по cosine similarity.
- Отдельный namespace для каждой пары чат/пользователь. Текст ответов модели, системный промпт, результаты инструментов и команды в Pinecone не записываются. Помимо текста сохраняются только тип записи и время.
- `/start`, `/help`, `/clear`, `/clear confirm`. Очистка затрагивает только память текущего владельца VPg06.

## Установка

Проверено на Python 3.13.13. Из корня репозитория:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
cp .env.example .env
```

Для Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

Заполните `.env`: ключи OpenAI и Pinecone, имя существующего готового индекса с размерностью **1536** и метрикой **cosine**, Telegram-токен и `ALLOWED_USER_IDS` (числовые ID через запятую). Бот принимает текст только в личном чате от разрешённых пользователей. Существующий индекс не удаляется и не пересоздаётся.

`OPENAI_BASE_URL` - адрес совместимого API-провайдера; он используется для агента, эмбеддингов и анализа изображения. Проверена модель `gpt-6-luna`; для другого провайдера выберите модель, поддерживающую Responses API, вызов функций и изображения. Модель эмбеддингов - `text-embedding-3-small`. Работа облачных API может тарифицироваться.

```bash
.venv/bin/python bot.py
```

Примеры сообщений:

```text
Запомни: моё учебное кодовое слово КЕДР-739.
Какое моё учебное кодовое слово?
Расскажи случайный факт о кошках.
Какая сейчас погода в Москве?
Пришли случайное фото собаки и опиши собаку на нём.
```

Для проверки без Telegram используется та же прикладная логика:

```bash
.venv/bin/python app.py --owner cli:demo "Какая сейчас погода в Москве?"
```

Каждый CLI-запрос сохраняется в памяти указанного владельца. Не используйте один owner для разных людей.

## Архитектура

Telegram / CLI → поиск прошлых сообщений → сохранение исходного пользовательского текста → Haystack Agent → внешние инструменты → ответ и фото.

Память читается перед записью текущего вопроса. Агент создаётся заново для каждого запроса: проверка памяти после повторного подключения не опирается на историю в оперативной памяти. Долговременная память добавляет записи без дедупликации; top-k=5 ограничивает контекст. Сам по себе поиск по сходству не гарантирует нахождения всех нужных фактов.

Мультимодальный инструмент держит изображение только в памяти текущего запроса. Агенту возвращается описание, а транспорт отправляет оригинальные байты и подпись пользователю. Технический журнал содержит названия инструментов и типы ошибок, без токенов и переписки. Телеметрия Haystack отключена.

## Проверка

```bash
.venv/bin/python -m unittest -v test_assistant
.venv/bin/python -m pip check
.venv/bin/python verify_live.py
```

Автономные тесты подменяют внешние сервисы. `verify_live.py` делает настоящие запросы к модели, Pinecone, Cat Fact Ninja, Open-Meteo и Dog CEO; использует синтетические учебные сообщения и уникальный тестовый namespace, удаляемый после проверки. Команда платная при платном API. В Telegram она ничего не отправляет.

Полные протоколы и тестовое фото сохраняются локально в игнорируемой папке `evidence/`. Обезличенный итог проверки приведён в `VALIDATION.md`.

## Ограничения

Учебное приложение обрабатывает запросы последовательно в одном процессе. Сетевые сервисы могут быть недоступны; при ошибке пользователь получает явное сообщение. Если генерация ответа упала после записи, исходное сообщение может уже находиться в памяти. Память является архивом сообщений, а не проверенной базой фактов. Размер сообщения ограничен 4000 символами; изображение - 8 MB. Результаты распознавания породы и описания модели могут содержать ошибки.

При использовании общего учебного Telegram-токена остановите предыдущий polling-процесс перед запуском этого бота. Команда `skip_pending=True` пропускает старые ожидающие обновления при запуске.

Секреты, окружение, данные, полные протоколы, снимки и локальный отчёт ДЗ исключены из репозитория.
